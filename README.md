# 🎧 ThinQuency Podcast App

A modern, user-friendly React application for exploring and managing podcast shows. Users can browse shows, filter by genre, sort by title or update date, track listening progress, and play episodes with a built-in audio player.

---

## Features

- Explore and browse thought-provoking podcast shows
- You can sort the shows alphabetically, by genre and most recent/oldest updated
- Your listening progress can be stored and reset with the click of a button
- There is a persistent audio player that let's you continue listening to an 
  episode while you are still browsing through the other shows

## Tech Stack

- **Frontend:** React, CSS Modules
- **State Management:** React Hooks (useState, useEffect)
- **Persistence:** `localStorage` API
- **Data Source:** Public API from [https://podcast-api.netlify.app]

## Installation

In order to install the project, follow these instructions: 

1. Clone the repository link: https://github.com/nicoledeklerk/CS20240226-_PTO2407_GroupA_Nicole-DeKlerk_DJS11.git
2. Open the project folder in your VS Code text editor
3. In the terminal run the command 'npm install' 
4. Once all the dependencies are installed, run 'npm run dev' 
5. In the terminal press 'o' + enter to open the project in the browser
6. Voila! You can now see the application in your browser

Podcast Application Navigation

1. On the homepage, you will be able to see a genre filter dropdown where you can search for shows according to the available genres you are interested in
2. To the right of that dropdown is another one that allows you to filter and sort shows according to their titles alphabetically as well as when they were updated
3. Underneath that you will see the shows avaiable to browse along with a preview image, mini-description, genre, how many seasons are available and when it was last updated. There is also a 'read-more' link that will take you directly to that show's detail page
4. On the far right side of the 'Sort by' dropdown you can also find a 'Reset Listening Button' that allows you to reset and clear the history of previously completed episodes
5. Once you have clicked on a show, you will be directed to the show page which gives you a description of the show as well as a season grid that shows you how many season are available and how many episodes each season contains
6. Once you click on a season, a pop-up modal will display which will show you all the available episodes with the audio tag that allows you to easily listen to an episode
7. Each episode also have a favourites button that allows you to remove or add an episodes to your 'favourites'. 
8. Upon listening to an episode in its entirety, the episode will be marked 'completed' so that you are able to see which episodes you have completed.
9. Any shows that you have selected as a favorite will be stored and you can easily access these titles by clicking on the 'Favorites' link in the header
10. There you will find all your favorited episodes that includes all it's details as well as an option to remove the episode from your 'Favorites'
